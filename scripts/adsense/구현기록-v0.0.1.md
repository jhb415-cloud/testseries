## 결정 기록

- 승인된 설계의 범위대로 원본 채점·문항·점수·저장 키를 보존하고, UI와 설명만 보완한다.
- 현재 cwd는 저장소가 아니므로 별도 clone/작업 브랜치로 격리했다. 기존 사용자의 작업 사본을 수정하지 않는다.
- 생성기/탐색 동작은 회귀 검사를 먼저 작성한다. 단순 원고 수정은 수동 검수한다.
- 공통 생성기는 공개 테스트 전체의 정확한 안내를 수정하고, 개별 고유 원고는 설명이 특히 부족한 상이한 메커니즘 중심으로 보강한다. 일괄 글자 수 목표를 두지 않는다.
- 개인정보 실제 보관 설정은 사용자에게 질문했다. 확인되지 않은 자동 삭제/기간을 사실로 만들지 않는다.
- Cloudflare 자동 배포 연결이 있으므로 우선 로컬 검증과 미리보기를 완성한다. 배포나 계정 변경 판단은 검증 결과를 기준으로 한다.
- 오래된 PRD의 HISTORIC_LOG 갱신 규칙보다 최신 CLAUDE/PROGRESS의 단일 PROGRESS 기록 규칙을 따른다.
