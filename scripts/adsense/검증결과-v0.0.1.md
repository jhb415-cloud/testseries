# 과몰입연구소 v1.3.8 보완 결과

작성: 2026-09-22. 승인된 기획 v0.0.2를 별도 브랜치 `codex/adsense-quality-v1.3.8`에서 구현했다. 운영 사이트 배포와 AdSense 재신청은 수행하지 않았다.

## 달라진 점

- 공개 테스트 59개의 안내를 다시 생성했다. 분기형 실제 문항 수, 겉/속 이중 결과, 검증하지 않은 소요 시간, 내부 변수 노출을 바로잡았다. 서로 다른 방식의 17개 테스트에 고유 진행·해석 원고를 넣었다.
- 시작·결과 화면에서 해설로 바로 이동할 수 있다. 홈 추천 카드는 실제 링크이며, JavaScript가 없거나 앱 파일 로드에 실패해도 전체 목록을 이용할 수 있다.
- 초기값과 개인 브라우저 클릭을 합친 참여 수를 화면에서 제거했다. 추천 순서와 실제 인기 순위를 구분하고, 밸런스 게임의 예시 수치가 실제 이용자만의 통계가 아님을 표시했다.
- 두뇌 나이 게임은 유지했다. 등급 범위의 무작위 재미용 숫자라는 설명을 시작·결과·공유에 추가했다. 채점, 난이도, 이미지, 저장 키는 보존했다.
- 소개·문의·개인정보 문서에서 서버 저장, 선택 로그인, Slack 문의 전달, AI 제작 활용 등 실제 코드와 맞지 않던 설명을 정정했다. **개인정보 보관 기간과 국외 처리 설정은 확인 전 초안이다.**

## 검증

| 항목 | 결과 |
|---|---|
| 생성기 회귀 검사 | 7개 통과. 분기 8문항, 분기 길이 범위, 순환/없는 노드 차단, 이중 결과, 시간 추정 제거, HTML 이스케이프, 런타임 변수 제거 |
| Playwright 브라우저 검사 | 9개 통과. JS 미사용/실패, 홈 링크·새 탭, 설정 로드 실패 복구, 설명→시작→결과→재시도, 두뇌 게임 15문항 등 |
| 공개 테스트 실행 | 59개 각각 기본 선택 경로로 결과까지 완료. 포인트 배분·슬라이더·컷신·분기 포함 |
| 원본 보존 | 61개 config 구조 비교: editorial 추가와 정신연령 설명 외 문항·결과·채점·이미지 값 동일. 두뇌 점수/나이 계산 블록 동일 |
| 정적 파일 | 공개 59개 목록 일치, 사이트맵 65개 로컬 경로 존재, 실제 사용 자산 참조 759개 존재, noindex·robots·사이트맵 보존 |
| 재생성 | 테스트 안내와 전체 목록 생성기 재실행 결과 동일 |
| 검토 | 별도 코드 검토에서 발견한 내부 변수 노출, 홈의 과도한 측정 표현, 가상 투표 비율 안내를 수정 |

브라우저 검사는 로컬 Chromium, 모바일 360×800 및 데스크톱 1440×1000에서 수행했다. 앱·엔진·이미지는 실제 파일이며 외부 인증·광고·서버 쓰기는 테스트 환경에서 차단했다. 따라서 로그인, 실서버 저장, 실제 광고 배치, 외부 공유 성공을 검증한 것은 아니다. 59개 기본 경로 검사는 모든 답변 조합의 전수검사가 아니다.

기존 스탯창 테스트의 미사용 `resultTemplate.image`는 없는 generic.webp를 가리키지만 16개 전용 결과 이미지가 우선 사용된다. 이번에는 이미지 데이터 보존 범위에 따라 이 구형 대체값을 변경하지 않았다.

## 배포·재신청 전 남은 사항

1. **운영자 확인:** Supabase 결과·프로필, Slack 문의, 분석 서비스의 실제 보관·삭제 설정과 국외 처리 사항을 확인하고 `/privacy/`를 확정한다. 기존 ‘12개월 자동 삭제’ 약속은 코드로 확인되지 않아 삭제했다. 임의 보관 기간을 새로 약속하지 않았다.
2. **배포 확인:** 확정된 변경을 배포한 뒤 실제 도메인에서 주요 시작·결과·설명·문의 경로를 확인한다. 계정/문의 테스트로 실제 데이터나 메시지를 보낼 때는 별도 명시적 요청 범위에서 수행한다.
3. **AdSense 계정 확인:** 현재 사이트 검토 가능 상태, ads.txt 인식, 자동 광고의 실제 위치를 확인한 후 재신청한다. 빈·진행·오류 화면의 광고 여부는 실제 계정 설정과 배포 화면에서 확인해야 한다.

Google의 승인 여부는 보장할 수 없다. 두뇌 결과 하나를 거절 원인으로 단정하지 않으며, 이번 작업은 현재 확인된 콘텐츠 설명·탐색·사실성의 약점을 줄이는 변경이다. 기존 꿈해몽/MBTI 보조 페이지의 noindex는 그대로 유지했지만, 이를 AdSense 검토 제외로 간주하지 않는다. 기존 기록의 ‘승인 후 자동 복구’, ‘최소 글 수/고정 대기 기간’은 이번 작업의 기준이 아니다.
