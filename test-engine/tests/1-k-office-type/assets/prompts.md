# K-직장인 유형 테스트 — AI 이미지 생성 프롬프트 (v3, 프롬프트 truncation 버그 수정)

**v1→v2 사이 발견한 버그**: `generate-assets.js`(및 `-gemini.js`)의 `parsePromptsFile()`은
`##` 헤딩 바로 다음 "한 줄"만 프롬프트로 읽는다(멀티라인 문단 미지원). v1에서 가독성을 위해
프롬프트를 여러 줄로 줄바꿈해서 썼더니, 실제로는 첫 줄만 잘려서 API에 전달됐음(예: cover는
"...wide group"에서 끊김) — 결과 이미지가 전부 레퍼런스 포즈를 복사한 이유의 상당 부분이 이
truncation 때문이었을 가능성이 높음. **이후 모든 프롬프트는 반드시 한 줄로 작성할 것**
(기존 mbti-stat-window 등도 실제로는 전부 한 줄 포맷이었음, v1만 예외적으로 잘못 씀).

**진행 방식**: rupang-master 1장만 먼저 완전한 프롬프트로 재테스트 → 여전히 레퍼런스 포즈를
복사하면 그때 다중 레퍼런스 등 다른 방향 검토, 정상이면 나머지 4개+커버 일괄 진행.
