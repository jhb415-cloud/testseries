자주 묻는 질문

Q. 결과가 정확한가요?
재미로 즐기는 오락용 심리테스트예요. 전문적인 심리 검사나 진단을 대체하지 않아요.

Q. 다시 할 수 있나요?
네, 결과 화면의 “다시하기” 버튼으로 몇 번이든 다시 해볼 수 있어요.

Q. 결과를 공유할 수 있나요?
결과 화면에서 카카오톡 공유와 결과 카드 이미지 저장을 지원해요.
