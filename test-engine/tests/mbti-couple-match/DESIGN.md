# #19 MBTI 커플 궁합기 — 설계 문서 (config.json 아님, UI 구현 전 상태)

다른 9개(mbti4/mbti4_dual)는 "문항 8개 풀면 코드 하나 나옴" 구조라 기존 엔진 확장으로
바로 처리되지만, 이건 **"내 유형 + 상대 유형을 고르면 궁합표를 조회"**하는 완전히 다른 흐름이라
지금 engine.js의 인트로→질문루프→결과 구조에 그대로 못 얹는다. 그래서 콘텐츠/로직 설계만
먼저 정리해두고, 실제로 만들려면 **인트로 화면에 드롭다운 2개(내 유형/상대 유형)를 받는
신규 화면 타입**이 필요하다 — `intro_input`(드롭다운 1개, #20에 이미 구현)과 비슷하지만
2개를 동시에 받고 곧장 결과로 넘어가는 점이 다름. 이 화면 타입 자체가 추가 엔진 작업이라
사용자 확인 후 진행할 것(다른 9개처럼 그냥 진행하지 않음).

## 궁합 등급 규칙 (내가 확정한 구체안 — 원문은 "2~3개 상보"/"3~4개 동일"처럼 구간이 겹쳐서
   그대로 구현이 안 돼 아래처럼 겹치지 않게 재정리함, 확인 필요)

`matchCount` = 두 사람 MBTI 4글자 중 정확히 같은 글자 개수(0~4)를 기준으로 1차 등급을 정하고,
아래 "보정 문항" 8개의 응답으로 미세 조정한다.

| matchCount | 1차 등급 | 의미 |
|---|---|---|
| 4 (완전 동일) | 평온각 (B) | 편한데 밋밋할 수 있음 |
| 3 | 힐링각 (S) | 서로 충전되는 조합 |
| 2 | 불꽃각 (A) | 티격태격 애정 조합 |
| 0~1 | 파국각 (C) | 노력 필요 조합 |

## 보정 문항 (8개, 원문 그대로 — 커플이 각자 답변)
각 선택지에 `delta`(-8~+8)를 매겨 1차 등급 점수(matchCount×25, 0~100)에 더하고,
80~100=힐링각 / 55~79=평온각 / 30~54=불꽃각 / 0~29=파국각으로 재환산하는 방식을 제안.
(이 델타 구조도 내가 임의로 정한 근사치라 확정 아님, 리뷰 필요)

1. 데이트 코스는 주로? — 내가 다 짬(0) / 상대가 짬(0) / 즉흥(+5, P매칭) / 반반(+8, 균형)
2. 싸우면 먼저 푸는 쪽은? — 항상 나(-3) / 항상 상대(-3) / 서로 눈치(-8, T충돌) / 시간이 해결(+5)
3. 둘이 있을 때 대화는? — 끊임없이 수다(+8, E매칭) / 침묵도 편함(+8, I매칭) / 한 명만 말함(-8, 불균형)
4. 여행 스타일은? — 계획파+계획파(+5, J매칭) / 계획파+즉흥파(+3, 상보) / 즉흥+즉흥(+5, P매칭)
5. 감정 표현 온도차는? — 둘 다 표현 많음(+8, F매칭) / 둘 다 담백(+8, T매칭) / 한쪽만 표현(-8, 온도차↑)
6. 갈등 해결 방식은? — 논리로 대화(+5, T매칭) / 감정 공유(+5, F매칭) / 방식 안 맞음(-8)
7. 함께 있을 때 에너지는? — 같이 나가 놀아야(+5, E매칭) / 집콕이 최고(+5, I매칭) / 서로 다름(-5, 조율 필요)
8. 미래 얘기 할 때? — 둘 다 큰 그림(+5, N매칭) / 둘 다 현실적(+5, S매칭) / 한쪽만 진지(-8, 온도차)

## 결과 카드 (템플릿형, 다른 9개와 동일 전략)
title: "궁합 판정: {grade}"
subtitle: "{typeA} × {typeB} 조합"
tip 예시: "너희 조합 판정: 힐링각 💕 (근데 세부 성향 차이는 서로 이해하고 가자)"
