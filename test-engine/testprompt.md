# Gemini 이미지 생성 프롬프트 — 21~60번 배치 재작성 (2026-07-17, 톤·매체 다양성 강화판)

## 왜 다시 썼나
1차 초안(ChatGPT로 뽑아본 21~30번 샘플, 사용자 첨부 스크린샷)이 전부 "청록/주황 브랜드 컬러 + 깔끔한
플랫 일러스트" 한 가지 톤으로만 나와서 40개를 연달아 보면 지루하고 AI가 찍어낸 티가 났음. 이번
재작성은 두 가지를 고쳤다.

1. **매체(그림을 그리는 방식 자체)를 40개 전부 다르게 지정** — `style-guide.md`가 이미 1~20번에서
   쓴 21종(레트로 픽셀/페인터리 초상화/플랫 벡터/세피아 잉크/폴라로이드 콜라주/페이퍼컷/네온사인/
   빈티지 신문콜라주/필름누아르/스테인드글라스/말풍선 코믹/코믹 액션패널/리소그래프/HUD 뇌스캔/
   홀로 포토카드/스티커 치비/글리치 CRT/민화/이중노출 사진/수묵 실루엣/사이버펑크 스캐너)와
   전혀 겹치지 않는 새 매체 40종을 아래에서 하나씩 배정했다(타로카드, 캠코더 파운드푸티지, 자수,
   목판화, 모자이크, 영수증 디자인, 만다라 등 — 목록은 파일 하단 표 참고).
2. **"AI 티" 줄이기** — 매끈한 에어브러시 3D 렌더나 좌우 완벽 대칭 일러스트 대신, 실제 물건을
   촬영한 느낌(그레인/미세 초점 흐림), 인쇄 미스레지스트레이션, 손으로 그은 삐뚤빼뚤한 선, 종이
   질감, 빛바랜 색 같은 "물성"이 느껴지는 묘사를 모든 프롬프트에 공통으로 넣었다(아래 공통 지침).

이 파일은 21~60번 **커버 1장 + 결과 샘플 1장**씩만 준비한 것이며, `test-engine/CLAUDE.md` 4-4
절차대로 Gemini(무료 채팅)에 넣어 레퍼런스를 뽑은 뒤 **각 테스트 폴더 안의**
`test-engine/tests/{번호}-{test_id}/assets/reference/`에 넣어주면(1~20번과 동일한 위치,
`generate-assets.js`가 실제로 읽는 경로) `generate-assets.js`로 나머지 세트를 일괄 생성한다. **41개 항목 모두 사용자 승인 없이 한 번에
전체 생성하지 않는다** — 배치 진행 방식은 기존 CLAUDE.md 4-7 규칙(순번대로, 배치마다 이미지
샘플 승인) 그대로 따른다.

## 모든 프롬프트 공통 지침 (AI-티 줄이기)
아래 문구를 모든 이미지 프롬프트에 기본으로 포함한다 — 실제 프롬프트 텍스트에는 자연스럽게 녹여 씀:
- "매끈한 3D 렌더/에어브러시 디지털 아트가 아니라, 실제로 만들어진 물건(사진/인쇄물/공예품)을
  촬영하거나 스캔한 것처럼" — 각 매체(사진/판화/자수/도장 등)에 맞는 물리적 질감을 명시
- 살짝 비대칭인 손맛, 은은한 필름 그레인/스캔 노이즈, 색 미스레지스트레이션, 종이·천·나무 등
  배경 재질의 텍스처를 의도적으로 포함
- 과포화 그라데이션 대신 절제된 팔레트(브랜드 컬러 청록 #085041/#1D9E75 + 주황 #D85A30을
  포인트로만 사용, 매체 고유 색감이 우선)
- **문서/UI/라벨/영수증처럼 원래 글자가 있는 매체를 쓸 때도 실제로 읽히는 문자는 렌더링하지 않는다**
  — 괘선, 도장, 바코드, 아이콘, 빈 라벨 박스 같은 그래픽 요소만으로 "문서처럼 보이는 느낌"을 낸다
  (한글/영문 텍스트 왜곡은 gpt-image-1의 고질적 실패 지점이라 항상 회피)
- SINGLE panel/scene only, do NOT split into two panels or windows (레퍼런스가 2패널이어도 적용)
