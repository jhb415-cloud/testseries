# 콘텐츠 톤 스타일 가이드 (누적 기록)

## 최우선 기준
- **핵심은 "재미"다.** 병맛은 그중 하나의 도구일 뿐, 매번 필수가 아니다.
- 주제 성격에 맞춰 아래 톤 중 어울리는 것을 골라 쓴다. 매번 같은 톤만 반복하지 않는다
  (index.json에서 최근 사용 톤 확인 후, 3회 이상 반복된 톤은 되도록 피한다).

## 톤 옵션 (주제에 맞게 선택, 섞어도 됨)
1. **병맛/장르 미스매치**: 사소한 주제를 진지한 장르(순정만화/스릴러/다큐/협박장)로 그려
   낙차로 웃기는 방식. MZ 어그로가 특히 필요한 가벼운 소재에 적합.
2. **진지·감성형**: 담백하고 신뢰감 있는 톤. 자기이해/심리 진단처럼 무게감이 필요한
   주제, 또는 공유했을 때 "있어보이는" 느낌을 주고 싶은 콘텐츠에 적합.
3. **깔끔·위트형**: 과장 없이 깔끔한 디자인에 카피 한두 줄로 웃기는 방식(절제된 유머).
4. **밈/드립형**: 병맛까진 아니지만 유행어·짤 감성을 가볍게 차용하는 톤.
- 이미지 스타일도 톤에 맞춰 조정: 진지형은 과장된 표정/협박장 콜라주를 빼고
  차분한 일러스트/사진풍으로, 병맛형만 위 병맛 공식(장르 미스매치, 콜라주 타이포,
  과장된 표정, 이질적 스타일 합성)을 적용한다.
- 브랜드 포인트 컬러: teal #085041/#1D9E75, orange #D85A30 (톤에 따라 원색 대비는
  선택적으로 병행)
- 타깃 MZ세대, 40대/라떼 톤 금지
- 실존 인물/캐릭터/작품 지칭 금지 (장르·스타일 키워드로만 묘사)
- 재미가 확보되지 않는 톤이라면(예: 너무 밋밋한 진지형) 사용하지 않는다 —
  "진지함"이 "심심함"으로 흐르지 않도록 카피/디테일에서 위트를 챙긴다.

## 이미지 매체(rendering technique) 다양성 원칙 (2026-07-10 추가)
**팔레트만 바꾸는 건 "다른 스타일"이 아니다.** 2026-07-10 K-직장인 유형 배치 세션에서
"컨셉은 다 다른데 이미지가 계속 비슷한 톤(플랫 벡터 두 개, 페인터리 세 개)으로만 나온다,
매번 플레이할 때마다 새로운 느낌이 들어야 한다"는 지적을 받음 — 이후 새 테스트의 이미지
컨셉(4-4)을 정할 때는 **아래 "사용된 매체" 목록과 겹치지 않는 렌더링 기법**을 먼저
검토할 것(색상/팔레트가 아니라 그림을 그리는 방식 자체가 달라야 함). UI 테마도 이미지
매체에 맞춰 함께 재설계한다(카드 질감/버튼 스타일/배경 톤 전부 — 색상 변수만 바꾸는 게
아님, `themes/office.css` vs `themes/fantasy.css` vs `themes/retro.css`가 서로 다른
접근 방식인 것과 동일).

## 테스트별 사용 톤·컨셉 기록 (매번 추가)
- mental-age: 병맛(장르 미스매치) — "정신연령 측정을 국가 공인 신체검사처럼 근엄하게"
  — Windows95 UI 병맛, 매체: 레트로 픽셀 UI
- k-office-type: 밈/드립형 — "회사 사원증을 목에 건 캐릭터가 유형별 소품을 들고 있는 밈
  카드", 매체: 플랫 벡터(굵은 아웃라인), 팔레트 그레이/네이비+브랜드 청록/주황, UI 테마
  신규 `themes/office.css`("모던 오피스 코르크보드" — 흰 카드+청록 상단바+체크박스톤 버튼)
- desert-island-type: 밈/드립형 — "무인도 표류자를 낡은 지도/일지에 손그림으로 그린
  탐험 기록", 매체: 세피아 잉크 펜화(크로스해칭), 팔레트 세피아/브라운 단색, UI 테마
  신규 `themes/journal.css`("낡은 양피지 일지" — 크림 배경+갈색 테두리+타자기 폰트)

  손으로 얼굴 가리는 클로즈업 폴라로이드)을 그리드 노트에 워시테이프로 붙인 다이어리 콜라주",
  매체: 폴라로이드/스크랩북 다이어리 콜라주, 팔레트 크림+오렌지/청록, UI 테마 신규
  `themes/scrapbook.css`("워시테이프 다이어리" — 크림 그리드 배경+손글씨 폰트(Gaegu)+
  워시테이프 코너 장식). 원래 style-guide 계획엔 real-vs-fake-mbti가 페이퍼컷, love-mode-mbti가
  스크랩북으로 돼있었는데, 사용자가 실제로 Gemini에서 뽑아온 레퍼런스가 반대 조합(겉/속=
  스크랩북, 연애 가면=페이퍼컷)으로 더 잘 맞아서 배정을 바꿔 채택함(둘 다 서로 다른 매체라
  다양성 원칙 자체는 유지됨).

  페이지처럼 벗겨지며 진지한 청록 얼굴이 드러나는 페이퍼컷 아트로 표현", 매체: 레이어드
