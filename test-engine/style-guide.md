# 콘텐츠 톤 스타일 가이드 (누적 기록)

## 최우선 기준
- **핵심은 "재미"다.** 병맛은 그중 하나의 도구일 뿐, 매번 필수가 아니다.
- 주제 성격에 맞춰 아래 톤 중 어울리는 것을 골라 쓴다. 매번 같은 톤만 반복하지 않는다
  (index.json에서 최근 사용 톤 확인 후, 3회 이상 반복된 톤은 되도록 피한다).

## 톤 옵션 (주제에 맞게 선택, 섞어도 됨)
1. **병맛/장르 미스매치**: 사소한 주제를 진지한 장르(순정만화/스릴러/다큐/협박장)로 그려
   낙차로 웃기는 방식. MZ 어그로가 특히 필요한 가벼운 소재에 적합.
2. **진지·감성형**: 담백하고 신뢰감 있는 톤. 자기이해/심리 진단처럼 무게감이 필요한
   주제, 또는 공유했을 때 "있어보이는" 느낌을 주고 싶은 콘텐츠에 적합.
3. **깔끔·위트형**: 과장 없이 깔끔한 디자인에 카피 한두 줄로 웃기는 방식(절제된 유머).
4. **밈/드립형**: 병맛까진 아니지만 유행어·짤 감성을 가볍게 차용하는 톤.
- 이미지 스타일도 톤에 맞춰 조정: 진지형은 과장된 표정/협박장 콜라주를 빼고
  차분한 일러스트/사진풍으로, 병맛형만 위 병맛 공식(장르 미스매치, 콜라주 타이포,
  과장된 표정, 이질적 스타일 합성)을 적용한다.
- 브랜드 포인트 컬러: teal #085041/#1D9E75, orange #D85A30 (톤에 따라 원색 대비는
  선택적으로 병행)
- 타깃 MZ세대, 40대/라떼 톤 금지
- 실존 인물/캐릭터/작품 지칭 금지 (장르·스타일 키워드로만 묘사)
- 재미가 확보되지 않는 톤이라면(예: 너무 밋밋한 진지형) 사용하지 않는다 —
  "진지함"이 "심심함"으로 흐르지 않도록 카피/디테일에서 위트를 챙긴다.
